# česky

Чэшская мова з беларускімі тлумачэннямі: 108 тэм A1–B2, 1124 карткі і 139 практычных заданняў.

Статычная PWA. Прагрэс захоўваецца на прыладзе ў IndexedDB. У наладах ёсць экспарт і імпарт рэзервовай копіі. Агучванне афлайн патрабуе лакальнага чэшскага голасу.

GitHub Pages: deploy from branch `main`, folder `/ (root)`.
